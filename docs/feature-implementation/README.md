## How to use these docs

1. Start with `APP_ARCHITECTURE.md` for system-level wiring.
2. Read the feature doc for the area you are modifying.
3. Verify listed source files before changing behavior.
4. Check "Current state" sections to avoid assuming incomplete features are production-ready.

## Source-of-truth reminder

These docs summarize current code behavior. If code and docs diverge, code is the source of truth and docs should be updated in the same PR.
